3 · Underlying data model (proposal)

Performances.Round TINYINT NOT NULL DEFAULT 0 — 0 = Final/only, 1 = Prelim, 2 = Semifinal, 3 = Heat (time-seeded, no advancement). Default keeps all existing rows valid.
UNIQUE (MeetId, EventId, AthleteId, Round) WHERE AthleteId IS NOT NULL — one mark per athlete per round; relays use SortedAthleteHash in place of AthleteId.
sp_RebuildLeaderboards: PB/SB/rank already use best-per-athlete (ROW_NUMBER / RANK), so they stay correct. Needs change: percentiles + EventStatistics currently count every row, so a prelim and a final from one runner would count as two marks and skew the population. Proposal: compute percentile population from each athlete's best mark per event only (then still assign each row its own percentile).
MeetScore: Peak/Depth already take athlete-event bests; Improvement uses meet-best per athlete-event. Verify no step double-counts rounds.
Placing: MeetPlacings attaches to the final round's performance when one exists.
