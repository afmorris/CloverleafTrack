Coaching tools

Planning tools for Cloverleaf track and field, built on our own results. Results, records, and athlete pages stay on cloverleaftrack.com.

Practice plans

This week's practices by day, built from blocks for each event group. Copy, print, and record measured attempts.

Template library

Ready-made practices for every event group. Start a plan from one, or save your own.

Season plan

Training phases on a calendar, with volume and intensity by week, tied to the meet schedule.

Goal pace builder

Start from an athlete's PR or a goal time, then get rep targets and splits for a workout.
